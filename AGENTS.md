# AGENTS.md

Guidance for coding agents working in this repository.

## What this is

`nimbleterminal.dev/ntfonts` is a Go module that embeds seven OFL-licensed font
families as 28 Latin subset faces (about 1.2 MB), served through
`ntfonts.Embedded`, a `Source` whose `Face(family, variant)` method is
nttypeset's `FaceSource`. It was extracted from gloss's typeset view. Develop
with Go 1.27.2; the module minimum is Go 1.26.

What it is not:

- It is not a font loader or parser; it returns bytes.
- It does no font discovery, downloads, or system-font lookup.

Longer-form docs: `README.md` (overview and the Fonts section), `DEVELOP.md`
(tooling and subset regeneration), `CHANGELOG.md`.

## Commands

All tasks run through [Go Task](https://taskfile.dev) (`Taskfile.yml`). Tasks
set `GOWORK=off`.

```sh
task ci                  # full gate, same as GitHub Actions (vulncheck needs network)
task test                # tests
task test-race           # race detector (needs a C compiler)
task lint                # golangci-lint v2 (installed into .task/bin)
task vet fmt fmt-check go-tidy-check go-verify
task fonts-check         # verify the 28 subsets against subsets.sha256
task build cross-windows cross-wasm
task notices             # regenerate THIRD_PARTY_NOTICES.md
task clean
```

Single test:

```sh
GOWORK=off go test -mod=readonly -run 'TestName' .
```

## Module layout

One Go module, `nimbleterminal.dev/ntfonts`. Never add local sibling `replace`
directives.

| Path | Role |
| --- | --- |
| `doc.go` | Package comment. |
| `ntfonts.go` | `Source`, `Embedded`, `Families`, `License`, `Licenses`; the `//go:embed` patterns. |
| `ntfonts_test.go` | Hash, family/variant, coverage and license tests (standard library only). |
| `Gloss[A-G]-{Regular,Bold,Italic,BoldItalic}.ttf` | The 28 embedded subsets. |
| `*.OFL.txt` | One license per family, embedded for `Licenses`. |
| `sources.json`, `subsets.sha256` | Pinned upstream sources and the hashes of the subsets. |
| `scripts/subset-fonts.py` | Regenerates the subsets and `subsets.sha256`. |
| `Go*.ttf`, `LICENSE.gofont` | Unused Go reference fonts and their license. |
| `internal/tools/notices` | Generates `THIRD_PARTY_NOTICES.md` (`task notices`). |

## Invariants

Breaking these breaks consumers, even if tests still pass.

- **Standard library only.** `go.mod` has no requires.
- **Never imports nttypeset**, not even in tests. `Face` is the contract; the
  `var _ nttypeset.FaceSource = ntfonts.Embedded` assertion lives in gloss.
- **Subsets change only through `scripts/subset-fonts.py`** with
  `fonttools==4.60.2`, then `subsets.sha256` is regenerated by the script.
  Never edit a `Gloss*.ttf` by hand.
- **Hashes are pinned.** `TestFontSubsetHashes` and `task fonts-check` must pass.
- **Family and variant names are the API.** `Families()` returns the seven
  upstream names; variants are `Regular`, `Bold`, `Italic`, `BoldItalic`.
- **The `Go*.ttf` files are not embedded.**

## Tests and reporting

- Automated tests do not establish visual quality. When reporting results,
  distinguish unit coverage from a visual check, and never claim a visual check
  that did not happen.
- Run `task ci` before finishing a change.

## Documentation

- Update `CHANGELOG.md` under an `Unreleased` heading for user-visible changes.
- Keep README, DEVELOP, and CHANGELOG consistent with the code.
- Run `task notices` after font changes; `task notices-check` enforces it in CI.
